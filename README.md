# Mangayomi Extensions

This is the independently maintained `mrandhawa14` extension repository. Its
indexes and extension source URLs resolve from this repository and do not
depend on an upstream pull request being accepted.

## Add it to Mangayomi

Use this URL as the anime extension repository in More > Settings > Browse:

```text
https://raw.githubusercontent.com//mrandhawa14/mangayomi-extensions/refs/heads/main/anime_index.json
```

The double slash intentionally keeps older Mangayomi releases from deriving a
GitHub profile picture for the repository icon. GitHub serves the same file as
the canonical single-slash URL.

The manga and novel indexes are also available:

```text
https://raw.githubusercontent.com/mrandhawa14/mangayomi-extensions/main/index.json
https://raw.githubusercontent.com/mrandhawa14/mangayomi-extensions/main/novel_index.json
```

This fork currently includes the maintained SFlix and MoviesFlix provider,
CineJoy, and compatibility fixes used by the curated index.
